# BrokVN GUI Editor

A Visual Novel Studio, Clickable Area (`CLICKERNEW`), Character Sprite Placement & Multi-Waypoint Walk Path (`IMAGENEW` + `IMAGEMOVE`) Tool for the **Brok VN Engine** (1920×1080 Native Canvas).

![BrokVN GUI Editor](logo.png)

---

## ✨ Features

- **1920×1080 Native Canvas**: Accurate engine aspect ratio with letterboxing and live drag & drop support.
- **Draggable Multi-Waypoint Walk Paths**: Physical real-time walking on canvas from Point A ➔ Point B ➔ Point C... with draggable pins and chained `IMAGEMOVE` script generation.
- **Spritesheet Animation Studio**: Automatic frame strip slicing, real-time animation playback loop (calibrated 8 FPS default), play/pause, frame step, reset, and scrubber controls.
- **Character Transformations**: Live Scale / Size slider (1%–500%), Horizontal Mirroring (Flip Character), 9 Anchor Origin points (`CENTER`, `TOPLEFT`, `BOTTOMCENTER`, etc.), and visual pivot crosshairs.
- **Layer & Depth Management**: Auto-depth based on Y-ground sorting or manual depth configuration (`DEPTH=`), plus clicker layer management (`LAYER=`).
- **Clickable Hotspots (`CLICKERNEW`)**: Interactive box drawing, snap-to-sprite bounds, presets (Full Screen, UI zone, etc.), and clean dialogue-free script generation.
- **Full-Screen Presentation Preview**: Press `F11` to test the scene in borderless full screen with interactive clicker testing.
- **Project Save & Load (`.brokproj`)**: Save your progress and load scene configurations anytime (`Ctrl+S`, `Ctrl+O`, `Ctrl+N`).
- **Overall BrokVN Scene Script**: One-click unified scene generator compiling backgrounds, sprites, walking paths, hotspots, and event stubs.
- **Native Windows Explorer**: Built-in Windows file dialogs that automatically remember your last browsed folder.

## 🚀 How to Run

### Quick Launch
Run `run.bat` or execute:
```bash
javac BrokVnClickAreaWindow.java Main.java
javaw BrokVnClickAreaWindow
```

### Build Standalone Windows EXE
Run `build_exe.bat` to generate a standalone application bundle in `dist\BrokVnGuiEditor\BrokVnGuiEditor.exe`.

## 📜 Example Generated Script

```ini
#====================================================
# OVERALL BROKVN SCENE SCRIPT
# Generated by BrokVN GUI Editor (1920×1080 Canvas)
#====================================================

EVENT=S01_SCENE_START
	BACKGROUND=BROK-APARTMENT-MAIN
	FADEIN=MEDIUM

	# Character Sprite & Animation
	IMAGENEW=IMAGE_DIRECTOR
		FILE=IMAGE_DIRECTOR
		DEPTH=28
		ANIMSPEED=8
		NBFRAMES=6
		SCALE=100
		ORIGIN=CENTER
		X=254
		Y=380
		ANIMEND=REPEAT

	# Multi-Waypoint Walking Path
	EVENT=S01_IMAGE_DIRECTOR_WALK_START
		IMAGEMOVE=IMAGE_DIRECTOR
			MOVEX=1502
			SPEED=3
			ENDEVENT=S01_IMAGE_DIRECTOR_ARRIVED

	# Scene Clicker
	CLICKERNEW=CLICK_DIRECTOR
		X1=200
		Y1=300
		X2=350
		Y2=480
		HIGHLIGHT=1
		TEXT=Examine Director
		CLICKEVENT=S01_CLICK_DIRECTOR
		HOTSPOT=1
		HOTSPOTICON=ICON_TALK
		CANDPAD=1
```
